通过贴近实际的场景、完整应用和共享待办列表，探索 GitHub Copilot 在软件开发生命周期中的应用。你将迭代地规划更改、编写代码、测试行为、审查 pull request，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为开发者主题的棋盘游戏提供众筹服务。团队的待办事项已作为 GitHub issue 提交，等待你开始处理。其中既有筛选和分页等功能工作，也有无障碍和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择符合你开发方式的环境。每个研讨会都有自己的设置步骤，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 以及实用的斜杠命令。

### [GitHub Copilot app][app]

并行运行代理会话、切换会话模式、在 Canvas 中协作，并在桌面应用中管理 GitHub issue 和 pull request。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issue 分配给异步代理、指导其工作、监控进度，并审查代理创建的 pull request。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
