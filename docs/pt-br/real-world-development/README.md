Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software com cenários realistas, um aplicativo completo e um backlog compartilhado. Você vai trabalhar de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é um novo desenvolvedor na Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com tema de desenvolvimento. O backlog da equipe já está registrado como issues do GitHub, prontas para você começar. Ele inclui funcionalidades como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de codificação.

## Escolha seu ambiente

O GitHub Copilot acompanha você onde quer que trabalhe. Escolha o ambiente que corresponde à sua maneira de desenvolver. Cada workshop começa com sua própria configuração e usa o mesmo cenário da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente agêntico no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra úteis.

### [GitHub Copilot app][app]

Execute sessões de agentes em paralelo, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [GitHub Copilot cloud agent][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, monitore o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
